# Matchmaker

Незадължителен Cloudflare Worker/Durable Object за събиране на групи от четирима. Той не държи игрово състояние: връща общ код, роля и място, след което PeerJS свързва устройствата с авторитетния домакин.

Клиентът го използва през публичната променлива `VITE_MATCHMAKER_URL`. Проверява се без публикация с `npm run check:matchmaker`; играта с room покана не зависи от него.
