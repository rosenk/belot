# Белот

Самостоятелна мобилна игра на български белот за четирима по двойки. Поддържа:

- локална игра за един човек срещу три бота;
- онлайн маса от четири отделни устройства чрез кратък room линк и PeerJS;
- чист TypeScript модел, Svelte 5/Vite клиент и Node тестове;
- незадължителен Cloudflare Worker/Durable Object matchmaker за случайни маси.

```bash
npm ci
npm run dev
npm run check
```

## Правила в тази версия

Играят **Вие + Партньор** срещу **Дясно + Ляво** с 32 карти. Редът е обратно на часовника. Раздават се 3+2 карти, наддава се, после още 3. Редът на обявите е спатия, каро, купа, пика, без коз, всичко коз. След обява три последователни паса я затварят; четири начални паса водят до ново раздаване. Контра се дава от противниковия отбор, реконтра — от обявилия отбор. След контра няма „бягане“ в по-висока игра.

- **Боя:** задължително се отговаря. В коз се качва. Без исканата боя се цака и при възможност се надцаква, освен когато партньорът държи ръката.
- **Без коз:** само се отговаря в исканата боя; картовите точки и последното 10 са двойни.
- **Всичко коз:** отговаря се и задължително се качва в исканата боя.
- Козът е `J, 9, A, 10, K, Q, 8, 7`; некозът е `A, 10, K, Q, J, 9, 8, 7`.
- Анонси: терца 20, кварта 50, квинта или по-дълга поредица 100; карета `10/Q/K/A` 100, `9` 150, `J` 200. При без коз няма анонси.
- Белотът (`K+Q` от козова боя) носи 20. Последната ръка носи 10 (20 на без коз); валатът носи още 90.
- Точките се записват в десетици и мачът е до 151. При едновременно достигане печели по-високият резултат; равният продължава.

### Избрани варианти и ограничения

Комбинациите се обявяват от играча преди първата му карта и стават публични за масата; необявена комбинация не носи точки. Белот и ребелот се обявяват с изиграването на съответните `Q/K` от козова боя. Когато карта попада едновременно в поредица и каре, системата предлага по-скъпата комбинация. Контра/реконтра умножават целия резултат от раздаването, включително премиите. При равни точки защитниците записват своите, а точките на обявилия отбор „висят“. Правилото „с капо не се излиза“ не се използва. Ботовете играят само по собствената си ръка, изиграните карти и публичните анонси.

## Мрежова архитектура

Домакинът пази и валидира единственото авторитетно състояние. Гостите изпращат команди, а домакинът връща различна проекция на всеки играч, която съдържа само неговата ръка. Състоянието на домакина се пази локално за 24 часа. PeerJS използва публичната си сигнализация; постоянна наличност и възстановяване след окончателна загуба на таба на домакина не са гарантирани.

Бутонът „Намери играчи“ използва публикувания matchmaker по подразбиране; `VITE_MATCHMAKER_URL` може да го замени. Опашката събира четирима и се затваря веднага след връщане на общ room код и роли; игровото състояние продължава само през PeerJS. Играта с покана не зависи от Worker-а. `npm run check` прави само Wrangler dry-run и не публикува.

## Публикуване

GitHub Actions проверява и публикува `main` като статичен Vite сайт на [rosenk.github.io/belot](https://rosenk.github.io/belot/). Workflow-ът изгражда сайта с base path `/belot/`; локалната разработка остава на корена. Matchmaker-ът е отделен Cloudflare Worker и допуска origin-а на GitHub Pages.

## Структура

```text
src/game/       чисти правила, състояние, ботове и проекции
src/online/     room линкове, локално възстановяване и PeerJS сесия
src/components/ Svelte представяне
matchmaker/     Worker/Durable Object опашка за групи от 4
test/           Node тестове
docs/adr/       архитектурни решения
```
