# 0007 — Статичният клиент се публикува в GitHub Pages

Дата: 2026-09-28
Статус: Прието

## Контекст

Клиентът няма собствен сървър и се нуждае от постоянен публичен адрес извън временния orb portal. Matchmaker-ът и PeerJS сигнализацията вече са отделни услуги.

## Решение

Публичното GitHub хранилище `rosenk/belot` изпълнява проверки и публикува `dist/` чрез официалните GitHub Pages actions при push към `main`. Pages build-ът използва `/belot/` като Vite base path. Cloudflare matchmaker-ът допуска точния origin `https://rosenk.github.io`.

## Последствия

Статичният клиент е достъпен без работещ orb и всеки push към `main` задейства нов deployment. GitHub Pages не поема игрово състояние, matchmaking или PeerJS сигнализация; наличността на онлайн режима продължава да зависи от тези външни услуги.
